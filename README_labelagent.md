# LabelAgent 智能标注与损失函数/优化策略平台

## 1. 软件简介

LabelAgent 是一套面向计算机视觉数据处理、智能标注、数据清洗、数据集构建、训练配置和消融实验的桌面应用。当前发布包采用 Windows 桌面程序形式运行，核心界面由本地服务与桌面 WebView 组合实现，用户无需手动打开浏览器即可使用主界面。

当前发布包主要包含五个功能模块：

1. **标注**：批量导入图像、Agent 自动标注、标注结果浏览与基础修订、多格式导出。
2. **清洗**：图像质量诊断、重复图检测、模糊图检测、越界标注检查、自动清洗、哈希缓存与 LSH 加速。
3. **数据集**：类别统计、训练/验证集划分、自定义数据集名称、自动生成 `dataset.yaml`。
4. **环境**：Python 解释器管理、外部 Python 环境导入、已安装依赖包与版本查看。
5. **训练与消融**：模型架构、损失函数、优化器、学习率策略、训练超参数、两阶段训练、训练看板、多组消融实验、CSV 导入与结果对比。

---

## 2. 发布包结构

解压后的目录应保持完整，不要只单独复制 `LabelAgent.exe`。

```text
LabelAgent/
├─ LabelAgent.exe              # 主程序
├─ _internal/                  # Python 运行库、WebView、静态资源及程序依赖
└─ workspace/                  # 工作目录、日志和运行结果
   └─ labelagent.log           # 运行日志
```

### 重要说明

- `_internal` 是程序运行所需目录，**不能删除、改名或与 EXE 分离**。
- `workspace` 用于保存运行期间产生的数据、日志和部分训练/模型相关文件。
- 当前发布形式为 ONEDIR 目录版，建议将整个 `LabelAgent` 文件夹压缩后交付给其他用户。

---

## 3. 系统要求

建议环境：

- Windows 10 / Windows 11 64 位；
- 建议 8 GB 以上内存；
- 进行深度学习训练时，建议使用 NVIDIA GPU，并另外配置匹配的 Python、PyTorch、CUDA 和模型环境；
- 使用 DeepSeek-VL、Qwen2-VL、OpenAI GPT-4o 等在线模型时，需要可用网络和对应 API Key；
- 如桌面窗口出现白屏，可检查系统是否具备可用的 WebView 运行环境。

普通启动、查看界面、数据导入、格式导出等基础功能不要求用户手动启动 FastAPI，也不要求先打开浏览器。

---

## 4. 启动方法

### 4.1 正常启动

1. 将整个 `LabelAgent` 文件夹解压到本地磁盘；
2. 双击：

```text
LabelAgent.exe
```

3. 等待桌面窗口加载；
4. 主界面出现后即可使用。

程序启动时会自动在本机建立内部服务，并加载 LabelAgent 桌面窗口。

### 4.2 日志位置

如果双击后没有界面、界面异常或功能报错，优先查看：

```text
workspace\labelagent.log
```

当前发布包日志会记录桌面程序启动地址和工作目录等信息。

# 6. 标注模块

顶部选择：

```text
🏷️ 标注
```

该模块用于图像导入、智能标注、标注结果浏览、标签调整和格式导出。

## 6.1 模型配置

当前界面提供以下 Agent 标注模型入口：

- **本地 Grounding DINO + SAM 2**
- **DeepSeek-VL**
- **阿里 Qwen2-VL**
- **OpenAI GPT-4o**

选择在线模型后，界面会显示 API Key 输入框。

### 本地模式

本地模式不需要填写 API Key，但实际自动标注是否可执行，取决于目标电脑是否已经准备好对应模型、权重及运行依赖。

### 在线模式

DeepSeek-VL、Qwen2-VL、GPT-4o 等在线模式需要：

1. 网络可用；
2. API Key 有效；
3. 对应模型服务可访问。

---

## 6.2 标注规则

界面支持设置：

- **统一标签名称**；
- **单图目标数量上限**；
- **文本标注提示词**。

当前界面默认值包括：

```text
统一标签：scratch_defect
单图上限：5
提示词：标注汽车, 划痕, 缺陷
```

使用时应根据实际任务修改。例如：

```text
统一标签：scratch
提示词：检测并标注金属表面的划痕区域
```

## 6.3 导入图像

## 6.4 Agent 自动标注


- 标注区域；
- 标签名称；

- 立即刷新预览结果。

**注意：当前版本前端未实现通过鼠标拖拽顶点、手工新建多边形或直接绘制框的交互，因此“微调”主要指标签修改和删除已有标注。**

# 7. 数据清洗模块

顶部选择：

```text
🧹 清洗
```

该模块用于诊断图像质量和清理异常样本。

## 7.1 数据来源

可直接导入：

- 原始图像文件夹；
- 多张原始图片；

也可以继续使用标注页面中已经导入的图库数据。

---

## 7.2 数据质量统计

诊断完成后界面会显示：

- 健康得分；
- 已扫描图像数量；
- 异常项数量；
- 诊断耗时；
- 模糊图数量；
- 重复图数量；
- 越界标注数量。

健康得分使用 0～100 的形式展示。

---

## 7.3 重复图检测加速

提供两种匹配策略：

### LSH 分桶匹配

```text
LSH 分桶匹配 O(N)
```

适合较大数据集，重点提升重复图检测效率。

### Pairwise 精确匹配

```text
精确 Pairwise O(N²)
```

对图像进行两两比较，计算量较大，更适合数量较小的数据集。

---

## 7.4 哈希缓存

可开启：

```text
开启哈希缓存
```

用于保存图像哈希计算结果，减少重复扫描时的计算开销。

如果更换了大量数据，或者怀疑缓存结果异常，可点击：

```text
清空缓存
```

---

## 7.5 质量诊断内容

当前清洗模块支持检查：

- 模糊图；
- 重复图；
- 越界标注；
- 空图相关清洗条件。

点击：

```text
开始诊断
```

后，程序会生成质量诊断报告。

---

## 7.6 自动清洗

可以按需勾选：

- 剔除重复图；
- 自动纠偏越界框；
- 剔除模糊图；
- 剔除空图。

点击：

```text
自动清洗
```

后，程序会更新当前数据，并返回：

- 清洗后保留图像数量；
- 已修复的越界标注数量。

## 9.4 EXE 与训练环境的关系

需要区分两类环境：

### LabelAgent 自身运行

当前发布包已经包含 Python 3.11 运行库以及程序自身运行所需的主要依赖，因此启动 `LabelAgent.exe` 不需要用户单独执行：

```text
conda activate
python run.py
pip install ...
```

### 深度学习训练

当前发布包检查到的 `_internal` 主要包含 GUI、Web、图像和基础科学计算相关依赖，并未将完整 PyTorch、CUDA、各类大型视觉模型权重全部打包进 EXE。

因此，真正进行 RT-DETR、YOLO、Deformable-DETR、Swin Transformer 等训练时，目标电脑通常仍需要准备一个可用的外部训练 Python 环境，并在“环境”页面导入对应 `python.exe`。

# 12. 损失函数选择

支持以下损失函数配置：

## CIoU Loss + BCE

适合作为标准边界框回归与分类组合方案。

## Focal Loss + EIoU

界面定位为难样本、类别不平衡缺陷任务方案。

## SIoU Loss

用于考虑方向和角度因素的边界框回归配置。

## DIoU Loss

考虑预测框与目标框中心点距离。

## GIoU Loss

使用广义 IoU 作为回归损失。

# 15. 基础训练参数

当前默认值：

```text
Epochs   = 12
Batch    = 8
ImgSize  = 640
LR       = 0.01
```

### 参数说明

**Epochs**：完整遍历训练数据的次数。

**Batch**：单次迭代使用的样本数量。显存不足时应适当减小。

**ImgSize**：训练图像输入分辨率。

**LR**：初始学习率。

实际参数应根据模型、数据量、GPU 显存和任务难度进行调整。

# 24. 常见问题

## 24.1 双击 LabelAgent.exe 没有反应

检查：

1. 是否完整解压；
2. `LabelAgent.exe` 与 `_internal` 是否仍在同一目录；
3. `_internal` 是否被误删；
4. 查看：

```text
workspace\labelagent.log
```

5. 检查杀毒软件是否隔离了 EXE 或 DLL。

---

## 24.2 出现白屏

可检查：

- Windows WebView 运行环境；
- `_internal` 是否完整；
- 是否有 DLL 被安全软件删除；
- `workspace\labelagent.log` 是否记录启动异常。

---

## 24.3 在线模型不能标注

检查：

- API Key 是否正确；
- 网络是否正常；
- 对应服务是否可访问；
- API 额度是否充足。

---

## 24.4 本地 Grounding DINO + SAM 2 无法运行

当前 EXE 发布包不代表已经自动包含所有大型模型和权重。

应检查：

- 模型权重是否存在；
- Python/模型环境是否配置；
- 模型代码是否可用；
- GPU/CUDA 环境是否匹配。

---

## 24.5 训练启动失败

重点检查：

1. 是否已经导入标注数据；
2. Python 解释器是否有效；
3. 训练环境是否安装对应框架；
4. 模型代码和权重是否存在；
5. CUDA / PyTorch 是否匹配；
6. Batch 是否超过显存能力；
7. 控制台日志是否给出具体报错。

---

## 24.6 数据集页面没有类别统计

数据集模块使用当前内存中的标注数据进行统计。

请先在“标注”页面导入并完成标注，然后再进入“数据集”页面。

---

## 24.7 导出按钮没有结果

请确认：

- 已经导入图片；
- 当前图片存在；
- 当前标注数据不为空；
- 已选择需要的导出格式。

# 26. 当前版本功能边界

本发布包的界面已经提供完整的数据处理和实验管理入口，但需要注意：

1. **模型选项不等于模型权重全部内置。**
2. **EXE 可以独立启动，不等于深度学习训练环境全部内置。**
3. **在线大模型需要 API Key 和网络。**
4. **本地大型模型通常需要单独准备权重和 Python 环境。**
5. **当前标注微调主要支持标签改名和删除，不包含完整 LabelMe 式手工绘制工具。**
6. **消融结果是否具有真实科研意义，取决于实际训练引擎、数据集、模型和指标计算是否真实接入。**

# 28. 最简用户操作说明

如果只需要快速使用，可按以下步骤：

1. 双击 `LabelAgent.exe`；
2. 进入“标注”；
3. 选择模型；
4. 设置标签和提示词；
5. 导入图片；
6. 点击“开始 Agent 自动标注”；
7. 检查并修改标签；
8. 进入“清洗”检查数据质量；
9. 进入“数据集”完成 Train/Val 划分；
10. 进入“环境”选择训练 Python；
11. 进入“训练与消融”选择模型、Loss、Optimizer 和超参数；
12. 启动训练；
13. 下载 `best.pt` 和 `results.csv`；
14. 如需科研对比，进入“消融”建立多组实验并导出结果。
